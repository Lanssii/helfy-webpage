# Doctorabs Landing Page

A responsive landing page developed as part of a frontend development assignment.

The goal of the project was to reproduce the provided design as accurately as possible using **HTML, CSS, and Vanilla JavaScript**, while maintaining responsive behavior across different screen sizes.

## Features

- Responsive layout for desktop and mobile devices
- Pixel-focused implementation of the provided design
- Interactive sliders for patient reviews and process steps
- Previous/Next slider navigation with smooth scrolling
- Vanilla JavaScript used for slider logic and DOM interactions
- Structured and responsive HTML/CSS
- Deployed version available via GitHub Pages

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## How to Run Locally

No complex setup is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/Lanssii/helfy-webpage.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

Alternatively, the project can be run using **VS Code Live Server** for a local development environment.

## Unfinished / Minor Refinements

The main functionality, layout, responsiveness, and visual implementation are completed.

Due to the five-hour assignment timeframe, there may be a few very minor visual differences in specific elements, such as small spacing or sizing variations in individual cards. These do not affect the overall functionality or responsiveness of the website and could be further refined with additional development time.
